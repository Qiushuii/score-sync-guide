# 曲式、解析卡与核对

## 卡片数据（`cards/m<N>.json`）

```json
{"cards": [
  {"m": 1, "title": "进行曲开场", "focus": ["大提琴", "低音提琴"],
   "gloss": [["格言动机", "大三和弦变成同根的小三和弦……"]],
   "body": "第一乐章标 Allegro energico……〔ref:wiki-m6〕"}
]}
```

- 每张卡从小节 `m` 开始，到下一张卡为止；有完整反复时用 `"pass": 2` 标第二遍。
- `focus`：卡片讲到的声部，名字栏里随文字一起放大变色（按中文声部名前缀匹配）。
- `gloss`：术语解释，卡片底部小字。
- `〔ref:id〕`：注释角标，对应 `references.json`；`tools/build_refs.py` 按片中顺序编号，同一出处全片共用一个号，并生成片尾清单。

## 写卡的原则

- **以对音乐本身的客观分析为主**：曲式与段落功能、主题与动机（写明小节号）、配器与织体、调性与和声事实、速度力度拍号的变化、表情记号。
- **每条事实性断言都要有依据**：谱面数据写小节号即可；文献加角标；二手转述在参考资料里注明。轶事（如"据某某回忆"）要说明可信度。
- 正文不点学者的名字，写"在分析中被称为……""有研究者认为……"，出处放片尾。
- 多个读法并存时（曲式之争、乐章顺序之争）都列出来，说明是诠释不是事实。
- 术语第一次出现时用一句话解释，观众多半不识谱。
- **读得完**：停留时间 ≥ 字数 ÷ 5 + 2 秒；一页放不下就分页（标题加"（续）"），太短的段并入相邻卡片。读 30 秒的文字讲接下来约 60 秒的音乐，不要太超前或太落后。
- 正片里不比较、不评价不同指挥家或录音（本项目用户的要求，可按需要调整）。

## 写卡用的读谱工具（只读谱面）

| 工具 | 输出 |
|---|---|
| `tools/score_facts.py <乐章>` | 每小节的调号、拍号、文字记号、排练记号、力度范围、在奏声部数、音符数、录音时刻 → `out/m<N>_facts.txt` |
| `tools/expr_marks.py <乐章> [--all]` | 表情、速度、性格类文字记号（`<words>`）及**所在声部** |
| `tools/similar_passages.py` | 按和声相似度找再现，允许移调 |
| `tools/find_melody.py` | 按旋律音程序列找主题再现，与移调无关 |
| `tools/motif_scan.py` | 按音程 + 节奏比例扫描动机 |
| `tools/find_motto.py <乐章> [--strict]` | 搜"大三和弦几拍内转同根小三和弦" |

结果都只是线索，进卡片前对谱。

## 交叉核对（`tools/cards_xcheck.py`）

**教训**：初稿里"铜管喇叭口朝上""弦乐摘下弱音器"这类笼统说法，多半是从"这一小节有这个文字记号"推出来的，没看它写在哪个声部。一轮系统核对查出十几处张冠李戴（喇叭口朝上的其实是双簧管、单簧管；海绵槌敲的是大锣不是钹；短笛晚了六个小节才进……）。

脚本逐句取出"第 N 小节""第 N–M 小节""第 N、M 小节"，以及句中的乐器名和说法，对照 MusicXML：

1. 点名的乐器在这些小节（±1）有没有音；
2. 记号说法（喇叭口、弱音器、espr.、突出、阻塞音、拨奏、弓杆、琴马、滑音、催促、不要赶……）有没有写在谱上，写在哪些声部，是否包括句中点名的乐器；
3. 力度记号（pp、fff……）在所说小节有没有；
4. 调号说法（"调号换成四个升号""调号清空"）对不对；
5. 拍号说法（"3/2 拍""改回二拍子""两拍的小节"）对不对；
6. "N 个声部"与实际有音的声部数是否相差太多。

报告 `analysis/卡片核对报告.md` 只列可疑，人工逐条判断。常见误报：速度词按惯例只写在最上一行（短笛、第一小提琴）；谱面德文拼写或大小写不一；正文本来就在说某乐器休止。

## 审稿（`tools/cards_review.py <乐章>`）

由对齐结果算出每张卡的出现时刻，检查停留时间、行数、参考资料 id，以及正文提到的小节离出现时刻是否太远，生成审稿文档 `analysis/m<N>_卡片审稿.md`。

**改卡片后要重跑 `cards_xcheck.py`、`cards_review.py` 和 `build_refs.py`。** 已经排好的谱（`data.js` 里带着卡片）要删掉重排。
